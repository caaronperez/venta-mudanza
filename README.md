# Venta de mudanza · CDMX

Catálogo temporal de artículos en venta (noviembre 2026). Se edita `items.json`; las fotos van en `images/`.

Campos por artículo: `id`, `title`, `price`, `delivery`, `condition`, `description`, `photos` (rutas `images/...`), `status` (`disponible` | `apartado` | `vendido`), `links.pickup`, `links.delivery` (links de pago de Mercado Pago).
